# ReasoningSummary

推理进行中的滚动摘要，以及结束后的一行折叠态。

## 进行中（`.reason`）

- 固定 **3 行**：最旧一行 `.old`（60% 不透明），最新一行 `.cur` 全对比并带 `.caret` 光标；新句进入时旧句上移淡出。
- 文字 `--thinking` 色、`--fs-sm`：推理不是结论，刻意比正文低一档；底 `--thinking-bg`，左侧 3px `--border-strong`。
- 右侧提示：`CTRL+O` 键帽（`.kbd`，像素字体）+ "展开完整推理"，下方 `N POINTS · 12S` 像素标签。
- Ctrl+O 打开右侧 400px 粘性面板（`.panel`），会话流不动、不换页；Esc 关闭。

## 结束后（`.thinking`）

- 折叠为一行：左 2px `--border-strong` 线，"推理过程 · 12s · 4 段"，右端 `ctrl+o`。

## 为什么

等待期间"它在想什么"是最有效的安抚，但完整推理会把结论推出首屏；3 行是两者的平衡，按需展开把选择权交给用户。

## 消费方提供

- 最近三句摘要、要点数、已用时；展开面板的分段文本与时间戳。
