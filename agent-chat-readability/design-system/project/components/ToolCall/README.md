# ToolCall

工具调用时间线：一组可折叠的卡片，每个工具三层信息。

## 三层

1. **意图**（`.intent`，正文色）："为什么做"，自然语言，一行。读者跟随的是推理链，不是 API 调用链。
2. **机制**（`.call`）：工具名与参数放在 `code` 片（`--code-bg`），耗时用像素字体 `--font-pixel`。
3. **输出**（`.result`）：默认折叠；等宽输出用 `.result.mono`（`--code-bg`，最大高度 220px 内滚动）；长输出保留首 4 行 + 尾 2 行，中间 `.cut`。

## 规则

- 组头 `summary` 汇总"N 个工具 · 耗时"；进行中展开，全部完成且正文开始后折叠。
- **失败项永不自动折叠**，并带 `.actions`（重试 / 跳过）。
- 左侧状态图标与 StatusChip 共用同一套 symbol。
- 嵌套 ≤ 2 层：输出区内不再嵌套卡片。

## 消费方提供

- 每个工具的意图文案、调用字符串、状态、耗时、输出文本（可选）。
