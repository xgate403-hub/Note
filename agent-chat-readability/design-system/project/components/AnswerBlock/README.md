# AnswerBlock

结论框：一条 Agent 消息里被"加冕"的唯一块，放在所有过程之前。

## 用法

- 左侧 3px `--accent` 边条，底 `--accent-bg`，标签 `结论` 用 `--text-2` 加像素字体角标 `ANSWER`（`--font-pixel`，`--fs-2xs`）。
- **每条消息最多一个**。两个结论框等于没有结论框（隔离效应）。
- 第一句就是答案；依据、表格、代码放在框外的正文里。
- 需要用户行动时，消息以 `.next`（"下一步"块）收尾：发丝线 `--border` 分隔，标签 `--text-3`，以问句结束。

## 消费方提供

- 结论文本（≤ 4 句）与可选的"下一步"文本。
