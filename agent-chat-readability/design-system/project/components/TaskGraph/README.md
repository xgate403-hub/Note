# TaskGraph

任务依赖图（DAG）与流程图的单色方案。

## 何时用

≥ 4 个有依赖 / 并行的任务用 DAG（左→右分层）；有判断分支用流程图（上→下、菱形判断）；否则用 PlanList。节点 ≤ 12，超过拆子图折叠。

## 规则

- 节点一律 `--surface` 底、1px `--border-strong` 边、`radius-sm`；状态只靠左上角 11px 图标（与 StatusChip 同一套 symbol）。
- 进行中：`--accent` 1.5px 描边 + `--accent-bg` 底，文字字重 600。等待人工只换描边为 `--warning`。未开始用虚线描边与 `--text-3` 文字。
- 边三档：已走过 `--text-3` 实线，当前路径 `--accent` 1.8px，未来 `--border-strong` 虚线。**图里唯一的颜色是当前路径。**
- 泳道：像素字体小标签（`--font-pixel`，`--text-3`）+ 一条 `--border` 发丝线，不用色块。
- 文字水平不旋转；节点标签 ≤ 8 字，耗时放 `--font-mono` 副标题。
- 图下方永远附文字版（有序列表写出依赖），可读屏、可复制、可搜索。
- 只有 running 节点有动画；截图与 `prefers-reduced-motion` 下静止。

## 为什么是单色

彩色填充的节点是流程图工具的默认样式，三四种底色同时出现会争夺注意力；状态靠图标形状已经足够，颜色预算只花在"现在在哪"。

## 消费方提供

- 节点（id、标签、层、状态、副标题）、边（起止、状态）、泳道（名称、层范围）。
