# Callout

四种语义提示框：说明 / 已完成 / 注意 / 失败。

## 规则

- 图标形状各不相同（圆 i / 圆勾 / 三角 / 方叉），颜色分别为 `--accent` / `--success` / `--warning` / `--danger`，底为对应的 `-bg`，描边为 `-line`。
- 只在语义成立时出现；**一条消息里最多一个红色块**，红色不做强调修辞。
- 标题 `--fs-md` 字重 600，正文 `--fs-sm`。失败框要说明"没有数据被修改 / 已做到哪一步 / 可以怎么办"。
- 不用 emoji 代替图标：平台渲染不一致，且无法随主题换色。

## 消费方提供

- 语义类型、标题、正文。
