# Agent 会话设计系统

把注意力留给文本的 Agent 对话界面规范：明亮与纯黑两套主题、一层视觉辅助、四款字体、参数化生成并逐项校验对比度的色板，以及会话里会出现的每一种消息块。源仓库 `agent-chat-readability/`（设计文档、可运行原型、截图脚本）。

## 原则

1. **结论先行，过程可折叠。** 注意力是串行的：先给答案再给证据，推理与工具调用默认收起。
2. **Agent 正文不用气泡。** 文档级长度需要 680px 的行长（≈ 42 个中文字）；气泡压缩行长、反白增加眩光。
3. **常驻只有一种有彩色。** 灰紫 `accent` 用于动作、进行中与结论框边条；`success` / `warning` / `danger` 只在状态出现时出现；装饰一律中性灰。红色一出现就一定是问题。
4. **状态 = 颜色 + 形状 + 文字。** 六种状态图标形状各异；视觉辅助主题换色不换形，再加纹理。
5. **任何时候只有一个元素在动。** 一个 spinner 或一个光标；呼吸 ≥ 1.2s；禁止 >3Hz 闪烁。
6. **颜色由参数生成而非手调。** OKLCH 色相等距、统一低色度、用对比度目标反解明度；四套主题出自同一份参数。
7. **像素字体只排拉丁短标签。** 角色名、计时、快捷键；不组成句子。

## 色彩

四个主题：`light`（暖纸白 `bg` #f8f7f4）、`dark`（纯黑 `bg` #000000，OLED 真黑）、`light-assist`、`dark-assist`（视觉辅助，深色改用深灰 #121316 而非纯黑）。

- 文字层级：`text` ≥ 15:1（辅助 ≥ 10）、`text-2` ≥ 4.5（辅助 ≥ 7）、`text-3` ≥ 4.5 仅元信息、`text-4` ≥ 3 仅占位。纯黑主题的次级、三级比明亮主题高一档，黑底上灰字更容易沉下去。
- 语义色：`accent` 285°（灰紫）、`success` 162°（灰青绿）、`warning` 78°（灰琥珀）、`danger` 18°（灰玫红），明亮主题色度 0.09–0.11，纯黑 0.10–0.11（黑底吃掉色度，需略高）。每个语义色配 `-bg`（极淡底）与 `-line`（描边）。
- 辅助主题语义色改为 紫 / 蓝 / 深黄 / 朱红橙，亮度差拉大；深色辅助的蓝提亮为天蓝，避免蓝光聚焦困难。
- ANSI 16 色（`ansi-*`）只用于日志：6 个色相等距，普通色 ≥ 5.5:1（明亮）/ ≥ 8:1（纯黑），亮色 ≥ 4.6 / ≥ 11。日志里的红比 `danger` 更灰、面积更小。
- 代码高亮只上 3 类色：`code-kw`、`code-str`、`code-cm`；`code-fn` 与 `code-num` 用正文色。
- 独角兽点缀 `uni-1/2/3` 是近灰的三色，只出现在 Agent 头像底；虹彩线、渐变进度条都已移除。

## 字体

| 角色 | 字体 | 理由 |
|---|---|---|
| 中文 | IBM Plex Sans SC | 与拉丁 Plex Sans 同一体系，字面、笔画、重心一致，混排不需补偿 |
| 英文 / 数字 | IBM Plex Sans（含 Text 450） | x 高度大，`0 1 I l` 可辨；纯黑主题正文用 450 补偿光渗 |
| 代码 / 日志 | JetBrains Mono（Google Fonts） | 字宽 0.6em，`{}()` 区分度高；**关闭连字** |
| 像素标签 | Departure Mono | 原生 11px 网格；给界面终端与数据感；无中文 |

字体栈：拉丁在前、中文回落（`families.sans`），数字与标点由 Plex Sans 承担。正文 `body` 15px / 1.7（笔记本 50–60cm 视距下 ≈ 0.26° 字高），手机 16px / 1.65；辅助层 16px / 字重 500 / 1.75。字重 700 只用于 ≥ 20px 标题。中文不用斜体，强调用字重或着重号。

## 间距与形状

4px 基数。轮次之间 `space-7`（32px）+ 发丝线，消息内块间 `space-3/4`，列表项 `space-1`。三个层级拉开差距，层级才可感知。圆角：`radius-sm` 按钮与 code 片、`radius-md` 卡片、`radius-lg` 气泡与面板。描边 `hairline` 1px（辅助层 1.5px）。深色主题层级靠更亮的面，不靠阴影。

## 图标

状态图标是一套 12×12 的 SVG symbol（`i-pending` 空心圆、`i-running` 四分之一弧、`i-done` 实心勾、`i-waiting` 时钟、`i-failed` 实心叉、`i-skipped` 横线），`currentColor` 上色，勾与叉的内部笔画用 `bg`。提示框图标 18×18（圆 i / 圆勾 / 三角 / 方叉）。不用 emoji 代替图标。

## 内容规则（给 Agent 的写作规范）

结论放第一块；一句一个意思，中文 ≤ 40 字；一段 ≤ 4 句；并列项用列表，只加粗前 2–6 个字的引导词；数字进表格（等宽右对齐），代码进代码块；不叙述过程（过程在工具卡里）；不确定要显式标出；以"下一步"交棒并用问句结束；红色、感叹号、emoji 不做修辞。

## 流式与交互

按帧（≥ 32–48ms）批量追加，只追加不回流；未闭合代码围栏立即按代码块渲染；光标流式期间静止、停顿才 1Hz 呼吸；推理进行中显示 3 行滚动摘要，Ctrl+O 打开侧栏，Esc 关闭；用户上滚后不抢滚动；失败项永不自动折叠；结束时只有光标淡出与操作栏淡入。

## 如何使用

- 组件样式在 `components/bundle.css`，只引用 `var(--token)`；`tokens.css` 由本页从 `tokens.json` 生成。主题切换：`<html data-theme="light|dark|light-assist|dark-assist">`。
- 代码仓库里只需 `tokens.css` + `bundle.css` 两个文件；调色改参数重新生成，不手改色值。
- 字体文件在 `fonts/`（OFL-1.1）；JetBrains Mono 从 Google Fonts 加载。
